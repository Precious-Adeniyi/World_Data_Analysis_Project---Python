# 🌍 World Data Analysis Using Python

## Overview
This project retrieves and analyses country-level data using the 
REST Countries API. It demonstrates API integration, data processing, 
and statistical analysis using Python.

## Key Analysis
- **Population Density** calculated for each country
- **Statistical Summary** — Mean, Median, and Standard Deviation 
  of population density
- **UN Membership** count across all countries
- **Euro Currency** usage across countries
- **Message Decoder** — pyramid pattern decoding algorithm

## Tools & Libraries
- Python
- Jupyter Notebook
- `requests` — API data retrieval
- `statistics` — statistical calculations
- REST Countries API

## Key Findings
- Mean Population Density: **436.93**
- Median Population Density: **88.06**
- Standard Deviation: **2031.54**

## How to Run
1. Clone the repository
2. Install dependencies:
```bash
   pip install requests
```
3. Open the notebook:
```bash
   jupyter notebook World_Data_Analysis.ipynb
```
